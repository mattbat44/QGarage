about=QGarage is a plugin-within-a-plugin framework. Each "App" runs in its own isolated uv virtual environment with fault tolerance, a modern card-based UI, and zero-friction developer experience. Features include: a dashboard with card-based UI for managing apps, per-app isolated virtual environments via uv, dynamic app loading with fault isolation, dark/light theme support, and a scaffold wizard for creating new apps. QGarage requires uv, which can be installed from powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex" on Windows Powershell. Check the website for uv here: https://docs.astral.sh/uv/getting-started/installation/#standalone-installer for instructions on other platforms.
